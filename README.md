# Мастерская Minecraft-модели

Windows-приложение для дообучения Qwen2.5-1.5B-Instruct на Minecraft-текстах. Можно также экспериментально ослаблять влияние выбранных текстов, сохраняя Minecraft-примеры.

## Что делать после скачивания ZIP приложения

1. Скачай свежий ZIP приложения с [GitHub](https://github.com/killeriibgx2-rgb/fly-dron/archive/refs/heads/main.zip) и распакуй его через **«Извлечь всё»** в обычную папку. Не запускай программу прямо из ZIP.
2. В распакованном проекте создай `models\Qwen2.5-1.5B-Instruct` и положи туда семь уже скачанных файлов Qwen: `model.safetensors`, `config.json`, `generation_config.json`, `tokenizer.json`, `tokenizer_config.json`, `merges.txt` и `vocab.json`. **GGUF для обучения не подходит.** ZIP приложения весов модели не содержит.
3. Положи Minecraft-тексты `.txt`, которые модель должна сохранить, в `data\minecraft`.
4. Если хочешь попробовать ослабить конкретные знания, положи примеры этих знаний в `.txt` в `data\to_forget`. Лучше включить разные вопросы и ответы по теме, а не только одно слово. Например, для темы Наполеона — несколько вопросов о нём и ответы, которые нужно разучить. Этот шаг необязательный.
5. Дважды щёлкни `setup_windows.bat` и дождись окончания установки.
6. Запусти `Start_LM.vbs`. Укажи папку `data\to_forget` в поле **«Необязательно: забыть эти .txt»**, если подготовил такие примеры. Оставь стартовые настройки и нажми **«3. Дообучить Qwen»**. После обучения приложение сохранит LoRA-веса отдельно; выбери результат в чате.

Если файлы Qwen лежат в другой папке, переносить их не обязательно: нажми **«Выбрать папку модели»** и укажи папку с файлами.

## Что значит «забыть»

Программа пробует изменить **обучаемые LoRA-веса**: повышает ошибку на выбранных текстах для забывания и снижает её на Minecraft-текстах для сохранения. Это настоящий эксперимент с изменением весов, но не гарантированное стирание всей темы из знаний модели. Нужны примеры текста/вопросов и ответов, которые забывать; одного названия темы мало. Исходный `model.safetensors` не перезаписывается: изменённый адаптер работает вместе с Qwen. Размер модели от этого почти не уменьшается.

Дообучение идёт на процессоре и может быть долгим; **RX 580 не используется**. Выбранные тексты остаются локально. Модельные веса и пользовательские тексты исключены из Git.
