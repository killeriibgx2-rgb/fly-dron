# Мастерская модели

Локальный настольный прототип для обучения небольшой языковой модели на собственных русскоязычных `.txt`-файлах — с нуля или продолжая сохранённые веса. Приложение пока не является Minecraft-модом: оно проверяет первый этап проекта — подготовку текста, обучение трансформера и генерацию продолжения.

Интерфейс сделан на PySide6. Обучение выполняется локально через PyTorch; программа не загружает выбранные тексты в интернет.

## Windows 10/11: установка и запуск

1. Установи Python 3.11 для Windows вместе с Python Launcher (`py`). Если Python 3.11 ещё не установлен, `setup_windows.bat` попробует поставить его автоматически через `py install 3.11`.
2. Дважды щёлкни `setup_windows.bat`. Он создаст `.venv` и установит библиотеки. Первичная установка может занять время и потребовать несколько гигабайт свободного места.
3. После успешной установки запускай `Start_LM.vbs` двойным щелчком — откроется окно приложения без консоли.

Если автоматическая установка Python не сработала, открой PowerShell, выполни `py install 3.11`, дождись установки и снова запусти `setup_windows.bat`. Установка библиотек использует увеличенный тайм-аут и несколько повторных попыток; если интернет всё равно оборвёт загрузку, запусти установщик ещё раз — pip продолжит проверять и ставить недостающие пакеты. Если ошибка повторится, сохрани последние строки окна.

## Установка обновления приложения

После того как обновление попадёт в `main`, закрой приложение и обнови его папку:

- Если скачивал проект через Git, открой терминал в папке проекта и выполни `git switch main`, затем `git pull origin main`. Если Git сообщит о незаконченных локальных изменениях, сначала сохрани их или скопируй нужные файлы в безопасное место.
- Если ставил из ZIP, скачай свежий ZIP ветки `main` и распакуй обновлённые файлы в папку проекта. Не удаляй папки `runs`, `data/texts`, `.venv` и `.venv-directml` — там могут быть модели, тексты и установленные библиотеки.

После обновления запускай тот же ярлык: `Start_LM_DirectML.vbs` для DirectML или `Start_LM.vbs` для обычной среды. Так как в этом обновлении не меняются зависимости Python, заново запускать установщик библиотек не нужно.

## Экспериментальное ускорение AMD RX 580

Обычный запуск `Start_LM.vbs` использует штатный PyTorch и может работать на CPU. Чтобы отдельно проверить RX 580 через DirectML:

1. Запусти `setup_directml_windows.bat`. Он создаст отдельную среду `.venv-directml` с совместимым PyTorch 2.4.1 и DirectML. Твоя обычная `.venv` не изменится.
2. После установки запускай `Start_LM_DirectML.vbs` и оставь устройство «Автоматически». Перед обучением приложение попробует сделать короткий шаг обучения на GPU; если операции не поддерживаются, переключится на CPU.

Это экспериментальный вариант: установка скачивает дополнительные библиотеки, DirectML может оказаться медленнее CPU или не поддержать нужные операции. Пакет [torch-directml](https://pypi.org/project/torch-directml/) помечен как предварительная версия; в его уведомлении указана возможная передача Microsoft сведений о GPU и операциях, которые не удалось выполнить на видеокарте. Содержимое твоих текстовых файлов приложением не отправляется.

## Первый запуск

1. Положи свои `.txt`-файлы в отдельную папку, например `data/texts/`. Кодировка UTF-8 предпочтительна. Подпапки тоже просматриваются.
2. В окне выбери папку текстов и отдельную папку для результатов.
3. Для первого теста выбери модель **«Маленькая»**, контекст 128 или 256, пакет 2–4 и 2–5 эпох. Большие настройки могут потребовать намного больше времени и памяти.
4. Выбери «Автоматически», CPU или доступное GPU. Если PyTorch не видит совместимый ускоритель либо он медленнее CPU, используй CPU.
5. Настрой эпохи, модель и остальные параметры по подсказкам ниже. Для первого теста не ставь 10 000 эпох: это число полных проходов по текстам, а не часы.
6. Нажми **«Обучить с нуля»**. Прогресс и сообщения будут показаны в окне. Кнопка остановки сохраняет checkpoint после текущего шага/эпохи.
7. Для продолжения обучения выбери папку уже сохранённого запуска с `latest.pt`, затем укажи папку текстов, где вместе лежат старые и новые `.txt`, и нажми **«Продолжить обучение»**. Программа сама возьмёт сохранённые веса, архитектуру, dropout и `tokenizer.json`; результат появится в отдельной новой папке, исходный запуск не перезапишется.
8. Во вкладке **«Попробовать модель»** выбери `latest.pt`. Кнопка **«Загрузить в RAM / VRAM»** заранее загрузит модель для генерации; **«Выгрузить из памяти»** освободит ссылки приложения на неё. После обычной генерации модель остаётся загруженной. Обучение автоматически выгружает её перед стартом, чтобы не занимать VRAM.

Модель, токенизатор и кэш токенов сохраняются в новой папке запуска внутри выбранной папки результатов. Входные тексты программа не изменяет. В текущих checkpoint не сохраняется состояние optimizer: при продолжении веса сохраняются, но состояние optimizer создаётся заново — это не точное восстановление прерванного шага.

## Что меняют настройки обучения

- **Размер модели / embedding, слои и головы внимания** задают ёмкость трансформера. Больше — может усвоить более сложные закономерности, но растут время обучения и расход RAM/VRAM. Размер embedding должен делиться на число голов.
- **Контекст** — сколько токенов модель рассматривает за раз. Длинный контекст особенно сильно увеличивает расход памяти.
- **Пакет (batch)** — сколько отрывков обрабатывается вместе. Больший пакет иногда лучше загружает GPU, но требует больше VRAM.
- **Словарь** — число частей слов, которые различает токенизатор. При обучении с нуля влияет на токенизацию и размер выходного слоя. При продолжении берётся словарь исходного checkpoint.
- **Эпохи** — полные проходы по обучающему тексту. Ползунок позволяет выбрать до 10 000, но это не длительность в часах: время зависит от размера корпуса, модели и устройства. Очень много эпох на небольшом корпусе часто приводит к переобучению; для длинного запуска сначала измерь время нескольких эпох. Большие значения требуют подтверждения, а остановка сохраняет checkpoint.
- **Скорость обучения** определяет величину изменения весов на шаг. Слишком высокая может ухудшить обучение; при дообучении обычно выбирают меньшую. **Оптимизатор AdamW/Adam** задаёт способ обновления весов; AdamW обычно удобный вариант по умолчанию.
- **Weight decay** мягко сдерживает рост весов (регуляризация); **dropout** случайно выключает часть связей во время обучения; оба могут помогать против переобучения, но слишком большие значения мешают учиться.
- **Доля проверки** оставляет часть токенов отдельно для контрольного показателя ошибки, а не обучения. Больше процентов — меньше данных остаётся для обучения.
- **Ограничение градиента** сдерживает чрезмерно большие обновления; 0 выключает его. **Seed** задаёт начальное случайное состояние для воспроизводимости. **Потоки CPU** влияют на параллельную подготовку/вычисления на процессоре; увеличение не всегда ускоряет.
- При продолжении обучения исходные веса, архитектура, контекст, dropout и словарь сохраняются. Настройки архитектуры из текущей формы для этой операции не применяются; число эпох, пакет, устройство, скорость обучения, weight decay, ограничение градиента и CPU-потоки задают новый этап обучения.

## Железо и ограничения

- Окно показывает обнаруженные CPU, число потоков и доступную/общую оперативную память. Можно менять устройство, размеры трансформера, контекст, размер пакета, словарь, число эпох, скорость обучения, оптимизатор AdamW/Adam, weight decay, dropout, ограничение градиента, долю проверки, случайное зерно и число потоков CPU.
- Оперативная память не является отдельным вычислительным устройством, которое можно «выбрать». На расход RAM/VRAM влияют размер модели, контекст и пакет; уменьшай их, если памяти не хватает.
- Приложение использует обнаруженные PyTorch CUDA/ROCm устройства, если они доступны в установленной сборке, и пробует обнаружить `torch-directml`, если тот установлен отдельно. **Поддержка AMD RX 580 в Windows не гарантируется.** Если подходящий backend не установлен или не поддерживает нужные операции, выбери CPU.
- Это учебная модель небольшого размера с случайной инициализацией. Несколько эпох на небольшом наборе не сделают её умным собеседником: она может выдавать бессвязный текст, повторяться и запоминать тренировочные фразы. Это прототип, чтобы проверить весь цикл обучения.
- При продолжении обучения используется токенизатор исходной модели. Точное восстановление состояния optimizer пока не реализовано: продолжение идёт с сохранённых весов, а optimizer создаётся заново.

## Подготовка текстов

Для чистого эксперимента используй тексты, которые можно законно обрабатывать и использовать для обучения. То, что модель не будет продаваться, само по себе не отменяет условия лицензии чужого текста. Сохраняй источники, убирай явный мусор и дубли, не добавляй личные данные. Программа читает только `.txt` и не загружает данные в сеть.
