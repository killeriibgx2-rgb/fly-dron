# Мастерская Minecraft-модели

Небольшое Windows-приложение для дообучения Qwen2.5-1.5B-Instruct на твоих Minecraft-текстах и проверки результата в чате. Приложение не является Minecraft-модом.

## Что делать после скачивания ZIP приложения

1. На GitHub скачай свежий ZIP приложения и распакуй его через **«Извлечь всё»** в обычную папку. Не запускай программу прямо из ZIP.
2. В распакованном проекте открой папку `models` и создай внутри папку `Qwen2.5-1.5B-Instruct`.
3. Переложи туда семь уже скачанных файлов Qwen: `model.safetensors`, `config.json`, `generation_config.json`, `tokenizer.json`, `tokenizer_config.json`, `merges.txt` и `vocab.json`. В итоге, например, должен быть путь `...ly-dron\models\Qwen2.5-1.5B-Instruct\model.safetensors`. **Не скачивай GGUF:** он для этого обучения не подходит. Сам ZIP приложения весов Qwen не содержит.
4. Положи нужные новые Minecraft-тексты `.txt` в `data\minecraft`. Подпапки тоже читаются.
5. Дважды щёлкни `setup_windows.bat` и дождись сообщения об успешной установке. Установка скачает нужные библиотеки и может занять время.
6. Дважды щёлкни `Start_LM.vbs`. В поле **«Темы, от которых отучать»** оставь или измени список (по одной теме на строку); приложение добавит к обучению примеры, которые учат вежливо возвращать разговор к Minecraft. Оставь остальные настройки как есть и нажми **«3. Дообучить Qwen»**. После окончания папка с адаптером заполнится сама; задай вопрос в чате.

Если файлы Qwen уже лежат в другой папке, переносить их не обязательно: в приложении нажми **«Выбрать папку модели»** и укажи папку, в которой лежат все семь файлов.

## Важно

- Дообучение сейчас выполняется на процессоре и может идти долго. **RX 580 не используется.**
- Обучается небольшая LoRA-добавка, а исходная Qwen остаётся нетронутой. Результат сохраняется в `runs\qwen`.
- Тексты в приложении читаются локально и не отправляются в интернет. Файлы моделей и Minecraft-тексты исключены из Git и ZIP приложения.
- Обычный Minecraft-текст помогает модели усваивать тему, но сам по себе не гарантирует хорошие ответы-собеседника. Для этого нужны качественные примеры Minecraft-вопросов и ответов.
- Список нежелательных тем не стирает факты из исходной Qwen. Он добавляет обучающие примеры перенаправления и правило для чата: модель должна говорить, что она здесь для Minecraft. Это меняет реакцию, но не гарантирует полного забывания темы.
- Старое обучение собственной Tiny-модели удалено из проекта, чтобы не путать его с Qwen.
