# Тексты для обучения

Сюда можно положить свои русскоязычные `.txt`-файлы в UTF-8. Приложение читает эту папку и подпапки. Само содержимое файлов Git игнорирует; в репозиторий попадёт только эта памятка.

Для первых тестов начни с нескольких небольших файлов. Сохраняй источники и условия использования сторонних текстов.
